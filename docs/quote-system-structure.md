# Nomodel株式会社 イベント業 見積もり自動化システム 構造設計書

> バージョン: 0.1（構造設計フェーズ）
> 対象: 下請け案件の見積もり作成業務の精算化・自動化
> 想定読者: Nomodel株式会社 役員 / 開発担当 / オペレーター

---

## 0. 設計の前提整理

### 0.1 ビジネス上の特徴
| 項目 | 内容 |
| --- | --- |
| 立場 | 下請け（元請け＝制作会社・代理店等から受注） |
| 業種範囲 | 音響・照明・映像・施工/設営・人材手配・機材レンタル・運搬（原則すべて受注可能） |
| 課金体系 | 人日 × 単価 + 機材 × 日数 + 運搬実費 + 諸経費 + 管理費・利益 |
| 案件特性 | 1件ごとに編成は違うが、構成要素（人材ロール・機材品目）は反復性が高い |
| 主な制約 | 元請けごとに様式・単価上限・税扱い・支払条件が異なる |

### 0.2 ボトルネック分解（複合的）
1. **単価検索コスト**: Excel/紙/記憶ベースの単価表を毎回参照
2. **拘束時間計算**: 搬入・リハ・本番・撤収を跨ぐ拘束時間と、残業/深夜/早朝/休日の割増判定
3. **フォーマット転記**: 元請けごとに違う様式へ毎回貼り直し
4. **粗利判断**: 利益が出るか、上限予算に収まるかの判断に時間がかかる

### 0.3 設計の目的
- **精算的**: 拘束時間・割増・原価・粗利を一意のロジックで自動計算し、属人化を排除
- **自動化**: 入力 → 計算 → フォーマット出力までを最短経路化
- **再利用**: 過去案件・テンプレートをマスタ化し、類似案件をワンクリックで複製

## 3. 計算ロジック仕様

### 3.1 拘束時間の分解アルゴリズム
入力: `start_at`, `end_at`
出力: `{ normal_h, overtime_h, late_night_h, early_morning_h, holiday_h }`

ステップ:
1. 区間を 30 分単位でスライス
2. 各スライスについて時刻・曜日・祝日を判定
   - 22:00 〜 翌 5:00 → 深夜
   - 5:00 〜 8:00 → 早朝
   - 土日祝 → 休日
   - 上記以外で1日 8h を超えた分 → 残業
3. 種別ごとに集計

### 3.2 人材ブロックの計算
```
for each staff_line:
    base   = unit_price * persons
    cost_total  = base * (normal_h + Σ split_h * cost_multiplier[type])
    price_total = base * (normal_h + Σ split_h * list_multiplier[type])
    margin = price_total - cost_total
```
※ 原価側と提示側で別 multiplier を持てる設計（原価は実支給ベース、提示は元請け請求ベース）

### 3.3 機材ブロックの計算
- 基本: `daily_list_price × quantity × days`
- 連泊割引: 2日目以降は `multiplier (例 0.7)` を乗算
- ロス料・消耗品: ライン単価×実数

### 3.4 運搬ブロック
- `base_rate + per_km_rate × distance_km × trips`
- 高速代・駐車場は実費パススルー（諸経費ブロックへ）

### 3.5 粗利上乗せ
- 集計順: `素原価合計 → 諸経費上乗せ → 管理費(%) → 利益(%) → 税`
- 元請けの `price_cap_rules` 違反は警告を表示（ブロックしない）

### 3.6 警告ルール（精算化のキモ）
| 警告 | 条件 |
| --- | --- |
| 粗利率低下 | quote.margin_rate < client.default_margin - 5pt |
| 単価下限割れ | line.unit_price < master.min_unit_price |
| 拘束超過 | 1日あたり総拘束時間 > 16h |
| 深夜未計上 | 22-5時の区間あり、かつ深夜割増ライン無し |
| 運搬未計上 | 機材ブロックあり、かつ運搬ブロック無し |

## 4. ワークフロー設計

### 4.1 新規見積もりの標準フロー
```
1. 案件カード作成（元請け選択・会場・期間入力）
2. テンプレ呼出 or 空ブロックから組立
3. 拘束スケジュール入力（搬入・リハ・本番・撤収）
4. 人材ブロック編集（役割×人数×ランク自動引当）
5. 機材ブロック編集
6. 運搬・諸経費ブロック追加
7. 計算エンジン自動実行 → 警告チェック
8. 粗利シミュレーター（粗利率スライダーで提示額調整）
9. プレビュー → 元請けフォーマット出力
10. 版数として保存 → 提出
```

### 4.2 改訂フロー
- 旧版をベースに新リビジョン作成
- 差分ハイライト（追加/削除/変更）
- 元請け提出履歴を時系列で保持

### 4.3 受注後の連携（Phase 4 想定）
- 確定見積 → 発注書（外注人材・レンタル）
- 確定見積 → 請求書ドラフト
- 実績粗利との突合 → 元請け別分析

## 6. 元請けフォーマット出力（Phase 3）

### 6.1 フォーマット定義モデル
- 元請けごとに `M_OUTPUT_FORMAT` テンプレを保持
  - 章立て順、用語マッピング（自社「機材費」→元請け「物品費」）
  - 表示粒度（明細／要約）
  - 税表記（税抜／税込／消費税別記）

### 6.2 出力種別
| 種別 | 用途 | 形式 |
| --- | --- | --- |
| 提出版 | 元請けへ提出 | PDF or 元請け指定 Excel |
| 内部精査版 | 原価・粗利・警告を全表示 | PDF / Web |
| 発注用 | 外注先別に分解 | PDF / CSV |

## 8. 用語集（社内統一）

| 用語 | 定義 |
| --- | --- |
| 案件 | 元請けから受注した1イベントの単位（複数日跨ぎ可） |
| 見積版（リビジョン） | 同一案件に対する見積もりの世代 |
| ブロック | 見積もりを構成する分類（人材/機材/運搬/施工/諸経費/値引/管理費） |
| 拘束時間 | 搬入開始〜撤収完了の総時間。人件費計算の基礎 |
| 割増 | 残業・深夜・早朝・休日に対する人件費倍率 |
| 連泊割引 | 機材複数日利用時の2日目以降割引 |
| 粗利率 | (提示額 − 原価) / 提示額 |
| 単価下限 | 各役割・機材ごとに設定された提示最低ライン |
