# Phase 0: マスタデータ ヒアリングシート

> 目的: 現行の単価情報（Excel/紙/記憶）を JSON マスタ化するために必要な情報を漏れなく洗い出す
> 使い方: 上から順にユーザー（出資者兼役員）または現場担当者がコメント欄に記入。回答が固まり次第 `docs/master-data/*.json` を生成する。
> 関連: `quote-system-structure.md` §2「データモデル」

---

## 進め方の3ステップ

1. **§A: スコープ確定** — どのマスタから着手するか優先度を決める
2. **§B: 各マスタの項目ヒアリング** — 1問1答で埋めていく
3. **§C: サンプル投入** — 各マスタ 3〜5 件の実データを暫定登録 → 計算ロジックの試走

回答粒度の目安:
- 「すでに表がある」→ 表の体裁とサンプル数行を提示してもらえれば構造抽出はこちらで行います
- 「頭の中にしかない」→ Q&A 方式で書き出していきます

#### B-1-4. 単価レンジの提供形式

- 形式2: テキストで列挙（例: 「TD Sr 原価 35,000 / 提示 45,000」）
- 形式3: 過去見積もり 3 件から逆算

## §C. サンプル投入

各マスタについて **3〜5 件** の実データを提示いただければ、`docs/master-data/` 配下に以下の形式で JSON 化します。

### サンプル: `m_staff_rate.json`
```json
[
  {
    "rate_id": "STR-TD-SR-001",
    "role_id": "TD",
    "role_name": "テクニカルディレクター",
    "rank": "Sr",
    "default_unit": "per_day",
    "standard_hours": 8,
    "cost_unit_price": 35000,
    "list_unit_price": 45000,
    "min_unit_price": 40000,
    "effective_from": "2026-04-01",
    "notes": "音響TD想定"
  }
]
```

### サンプル: `m_equipment.json`
```json
[
  {
    "equipment_id": "EQ-PA-001",
    "category": "PA",
    "name": "PAスモールセット A",
    "spec": "メイン2発+ステモニ2+ミキサー16ch",
    "stock_status": "自社保有",
    "daily_cost": 30000,
    "daily_list_price": 50000,
    "multi_day_discount": { "from_day": 2, "multiplier": 0.7 }
  }
]
```

### サンプル: `m_rate_rule.json`
```json
[
  { "rule_id": "RR-LATE", "rule_type": "深夜", "condition": { "start": "22:00", "end": "05:00" }, "multiplier": 1.5, "applies_to": "人材" },
  { "rule_id": "RR-OT",   "rule_type": "残業", "condition": { "daily_over_h": 8 },                  "multiplier": 1.25, "applies_to": "人材" }
]
```

## 進め方の提案

1. **まず §A を埋める**（5分）— 着手対象を絞る
2. **§B-1（人材マスタ）から開始** — 単価検索コストの最大要因
3. 既存 Excel があればこちらにコピペ、無ければ口述ヒアリングで構造化
4. 3〜5件の実データで JSON 雛形を完成 → 計算エンジンの試走で違和感を検出
5. 違和感を反映して項目追加・修正 → 残マスタも同じ流れで進める

> このシートに直接書き込むか、別ファイルに回答を寄せていただければ、回答内容を読み取って `docs/master-data/` 配下に JSON 雛形を生成します。
